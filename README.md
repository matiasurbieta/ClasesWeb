# ClasesWeb: a Todo app in Next.js and Nest.js

Teaching project with two apps:

- `frontend/`: Next.js 16, React 19, shadcn/ui. Entity, list and dialog form for `Todo`.
- `backend/`: Nest.js 12, MongoDB through Mongoose, Swagger/OpenAPI generated by the CLI plugin.

## Branches

| Branch | What it contains | Guide to follow |
|---|---|---|
| `initial` | Starting point: UI components with no state, empty page, complete backend API. | `frontend/TODO-LOGIC.md`, `backend/TODO-API.md` |
| `full-apps` | The frontend guide applied (todos in an in-memory array, create, toggle, edit) plus the OpenAPI client generation set up. | `frontend/API-CLIENT.md` |
| `full-api` | The frontend talks to the backend through the generated client, plus a how-to for adding OAuth login to both apps. | `OAUTH.md` |

## Run

```bash
# backend (MongoDB in Docker, API on http://localhost:3001, Swagger UI on /api)
cd backend && docker compose up -d && PORT=3001 npm run start:dev

# frontend (http://localhost:3000)
cd frontend && npm run dev
```

Once `OAUTH.md` is applied, both apps also need their variables: `backend/.env` and `frontend/.env.local`,
listed in `OAUTH.md` section 6. If something fails, see its section 7.
